# Weather Clock screensaver

Rust + OpenGL Windows `.scr`. See README.md for what it is; THIRD_PARTY.md for background credits.

## After every code change that builds

The owner tests by running out of `dist\`, so after any change to the code or shaders, finish by running:

```powershell
powershell -NoProfile -File tools\dev-dist.ps1
```

This runs `cargo build --release` and refreshes `dist\Weather Clock.scr`, `dist\Weather.Clock.scr` (both are copies of
`target\release\wxscr.exe`) and `dist\Settings.bat`. Never leave `dist\` holding a stale `.scr`.

`dist\Settings.bat` opens the config screen (`Weather Clock.scr /c`); Windows 11 has no Configure entry on right click.
`dist\` is gitignored, so the batch file is generated by `tools\dev-dist.ps1`; do not delete that part of the script.

Release installers are separate: `installer\build-installer.ps1` builds `dist\WeatherClock-Setup-<version>.exe`.

## Adding a background

Touch every place that lists backgrounds: `NAMES`, `IDS`, `TIME_SCALE`, `CREDITS` and `single()`/`multi()` in `src/bg.rs`
(array lengths too), the shader under `src/shaders/`, and a row in THIRD_PARTY.md with author, URL, licence and changes.
Shaders are GLSL 1.20 behind a Shadertoy-style header: zero-initialise locals and `out` values.

## Testing visually

`wxscr.exe /snap <prefix> [w h [bg index]]` writes PNGs. Run it through PowerShell `Start-Process ... -Wait`; from the
bash tool it hangs.
